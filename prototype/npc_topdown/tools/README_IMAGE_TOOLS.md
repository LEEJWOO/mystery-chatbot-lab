# 트로메라 인물 그림 도구 설명서 (blank_kit · hair_lock · char_layers · body_base)

## 준비 (한 번만)
- Python 3.10 이상
- `pip install numpy pillow scipy matplotlib opencv-python`
- 다섯 파일(`hair_lock.py`, `char_layers.py`, `blank_kit.py`, `expr_extract.py`, `body_base.py`)을 **같은 폴더**에 둔다.
  `char_layers.py`는 `expr_extract.py`를 불러 쓴다.
- 모든 도구는 그림 크기·위치를 바꾸지 않는다(표시 규칙: 같은 인물 그림 사이 확대·축소·이동 금지).
- 내용과 상관없는 일반 이미지 처리라, 공개 저장소에 못 올리는 그림도 각자 PC에서 그대로 돌리면 된다.

## 파일 이름 규칙 (공통)
`번호-직업-자세-표정.png` 예) `05-pianist-default-neutral.png`
- 자세: `default` / `think` / `point` / `crossed`
- 표정: `neutral smile laugh suspicious surprised troubled embarrassed annoyed sad furious panic darksmile`
- 달걀귀신(얼굴 비운 기본판): `번호-직업-자세-blank.png`, 공통 마스크: `번호-직업-자세-mask.png`

---

## 1. blank_kit.py — 달걀귀신 점검·마무리
원본 자세 그림과 얼굴을 비운 그림을 비교해 ① 바뀐 범위 점검 ② 투명 바탕 입히기 ③ 표정 인페인트용 공통 마스크 만들기.

```
python3 -I blank_kit.py <원본 폴더> <빈 얼굴 폴더> <출력 폴더> [--preview 확인.png]
```
- 원본 폴더: `…-neutral.png`(투명 배경 원본)
- 빈 얼굴 폴더: `…-blank.png`(NovelAI 인페인트 결과, 흰 배경이어도 됨)
- 출력: 투명 바탕을 입힌 `…-blank.png` + `…-mask.png`
- 화면에 '바깥 변경' 경고가 나오면 얼굴 밖(머리 윤곽·몸)까지 바뀐 것 → 다시 인페인트.
- 얼굴 안쪽이 지저분한 건 괜찮다(표정 조각이 늘 덮는 자리).

## 2. hair_lock.py — 앞머리 고정
앞머리가 눈을 가리는 인물용. 표정을 넣을 때 NovelAI가 앞머리 가닥까지 새로 그려 표정마다 앞머리가 달라지는 문제를 없앤다.
달걀귀신 기본판의 앞머리를 '뚜껑'으로 고정하고, 표정 그림에서는 피부 위의 바뀐 곳만 쓴다.

```
python3 -I hair_lock.py --base 기본판-blank.png --var 표정1.png 표정2.png … --out 출력폴더
```
출력(표정마다 3개)
- `표정-face.png`: 투명 얼굴 조각(앞머리에 가린 곳은 이미 잘림). **화면 조립은 기본판 위에 이 한 장.**
- `표정-preview.png`: 합성 결과
- `표정-check.png`: 원본 | 결과 | 차이 지도(빨강=버린 앞머리, 초록=쓴 곳)

조절값
- `--skin-tol 28`: 피부색 허용 거리. 키우면 앞머리 가장자리까지 표정을 쓰고, 줄이면 더 엄격하게 앞머리를 지킨다.
- `--feather 2.0`: 경계 흐림. 이음매가 보이면 3~4로.
- `--edge 1.2`: 앞머리 가장자리 보호 폭.

주의
- 기본판과 표정은 **반드시 같은 그림에서 인페인트로** 만든다(새로 생성한 그림은 안 맞음). 크기가 다르면 멈춘다.
- 인페인트 마스크에 앞머리가 들어가도 괜찮다(도구가 되돌림).

## 3. char_layers.py — 인물 레이어 묶기(화면용)
자세 그림 + 표정들을 화면용 webp 조각과 표(json)로 묶는다. 옛 방식(neutral 바탕+표정+표정 마스크)과 달걀귀신 방식(blank+공통 mask+모든 표정)을 둘 다 받는다.

```
python3 -I char_layers.py <인물id> <원본 폴더> <출력 폴더> --table 표.json [--preview 미리보기.png] [--fresh]
```
- `--table`: 결과를 적을 표. **각자 PC에서는 꼭 지정**(안 하면 저장소의 `src/assets.web.json`을 찾는다).
- `--preview`: 자세·표정별 얼굴을 늘어놓은 확인용 그림.
- `--fresh`: 그 인물 항목을 새로 만듦(없으면 이번에 찾은 파일만 덮어씀).
- 표정 조각 경계 처리는 `expr_extract.py`가 한다(테두리 띠·회색 면 제거, 흰 번짐 정리, 턱 고정).
- 참고: 표에 적히는 눈 위치(`eye`, `ed`)는 예전 자동 맞춤용 값이다. 지금 표시 규칙(인물별 배율·y값 1개)에서는 화면 보정에 쓰지 않는다.

## 4. body_base.py — 맨몸 기준판 반자동
옷 입은 기본 자세(얼굴 비운 그림)를 NovelAI 인페인트로 여러 번 덮어 가며 벗겨 내는 작업을 돕는다.
NovelAI 생성은 사람이 하고, 고르기·다음 범위 안내·마무리를 도구가 한다.

```
python3 -I body_base.py score    --orig 원본.png --zone 옷마스크.png --cand 후보1.png 후보2.png … --out 점수.png
python3 -I body_base.py nextmask --orig 원본.png --zone 옷마스크.png --cand 고른후보.png --out 다음마스크.png
python3 -I body_base.py merge    --base 후보A.png --take 후보B.png:x0,y0,x1,y1 --out 합본.png
python3 -I body_base.py finish   --orig 원본.png --zone 옷마스크.png --cand 최종.png --out 결과폴더
```
- `원본`: 옷 입은 기본 자세(얼굴 비운 그림, 투명 배경). 이 그림의 머리·머리카락이 최종본에 그대로 남는다.
  **회차가 바뀌어도 `--orig`에는 언제나 첫 회차 원본을 넣는다.** 이 그림과 비교해 '안 바뀐 곳 = 아직 남은 옷'으로 센다(피부색 비슷한 아이보리·흰 옷도 놓치지 않게).
- `--zone`: **첫 회차에 옷을 덮은 인페인트 마스크**(흰색=옷). 손·목처럼 원래 피부인 곳은 칠하지 않는다(안 바뀌면 '남은 것'으로 셈). 없어도 돌지만, 머리카락과 옷 색이 비슷한 인물(예: 보라 머리+검보라 드레스)은 사실상 필수.
- `score`: 후보마다 옷 영역 중 피부 비율·남은 옷 비율을 계산해 순위. 1등이 다음 회차의 원본. 점수표 그림에서 파랑 = 남은 옷.
- `nextmask`: 남은 옷을 `--grow`(기본 24px)만큼 넉넉히 넓힌 마스크. **경계가 옷 위에 놓이면 그 자리에 옷 색 띠가 남고 회차마다 쌓여 그물무늬가 되므로**, 경계가 이미 드러난 피부·배경 위에 오도록 일부러 넘친다. 첫 마스크를 grow보다 더 넘거나 턱 위로는 가지 않는다. 다음 회차에 이 범위만 덮으면 이미 잘 나온 피부를 다시 그리지 않는다
  (NovelAI 화면에 마스크를 불러올 수 없으면 칠할 범위를 보는 안내 그림으로 쓴다).
- `merge`: "몸통은 3번, 다리는 5번"처럼 사각형 부위를 골라 경계를 부드럽게 섞는다(`--feather 12`).
- `finish`: 턱 위와 바뀌지 않아야 할 곳을 원본으로 되돌림(머리 픽셀 일치 보장) + 흰 배경 투명화 + 점검표
  (원본 | 결과 | 원본 윤곽 | 남은 옷 | 얼룩 강조). 얼룩 강조 칸에서는 번진 면·이음매·색 얼룩이 도드라져 보인다.
- 남은 옷 비율은 근사값이다. 드러난 피부가 원래 옷 색과 거의 같으면(아이보리 옷 등) '안 바뀐 곳'으로 잡혀 남은 것에 조금 섞일 수 있다. 어두운 머리카락 일부가 옷으로 잡힐 수 있으니 숫자보다 점수표 그림을 본다.
- 턱 위치는 자동으로 찾고, 틀리면 `finish --chin Y`로 지정.

### 인페인트 요령 (실제 시험에서 확인)
- 마스크 경계를 옷 위에 두지 않는다. 남은 옷보다 20~30px 넉넉히, 이미 그려진 피부까지 걸쳐 칠한다.
- 작게 쪼개 여러 번 칠하면 경계 띠가 쌓인다. 회차마다 '남은 옷 전체 + 여유'를 한 번에 덮는다.
- API로 마스크를 1/8 크기(128×128)로 보내면 경계가 8px 계단이 되어 띠가 두꺼워진다. 가능하면 원래 크기로, 아니면 여유를 더 크게.

### 반복 순서 (동업자·사용자 분담 예)
1. 동업자: 원본 + 옷을 넉넉히 덮은 마스크(이 마스크를 `옷마스크.png`로 저장)로 '옷 없음' 가중치를 높여 후보 4~8장
2. `score` → 1등을 다음 회차 원본으로, `nextmask`로 다음 범위 확인 → 다시 인페인트
3. 남은 옷이 거의 0이 될 때까지 2를 반복(사용자는 회차가 끝날 때 점수표만 가끔 확인)
4. 부위별로 더 나은 후보가 있으면 `merge`
5. `finish` → 점검표의 얼룩 강조를 보고 사용자가 음영만 손봄

## 권장 순서 (인물 한 명, 한 자세)
1. 원본 자세 그림 `…-neutral.png` 준비
2. NovelAI로 얼굴 비우기 → `blank_kit.py`로 점검·투명 바탕·공통 마스크
3. 공통 마스크로 표정 인페인트(표정별 png)
4. 앞머리가 눈을 가리면 `hair_lock.py`, 아니면 `char_layers.py`로 묶기
5. `-check.png` / `--preview` 그림으로 눈 점검
