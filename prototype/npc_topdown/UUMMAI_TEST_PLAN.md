# UUMMAI 실측 계획 (v0.3 기준)

결과는 항목 번호와 함께 "예상대로 / 다름(무엇이)" 으로 기록한다. 같은 시험은 **새 대화방**에서 2회 반복해 우연을 배제한다.

## A. 로어북 동작 시험 (전용 시험 대화방)

### A-0. 준비
메인 프롬프트 맨 위에 아래 블록을 임시로 붙인다(시험 후 삭제).

```
[로어북 시험 모드 — 시험 후 삭제]
- 이 시험 동안 Troemerei 태그 규칙은 무시하고, 평범한 문장 한두 줄로 짧게 답한다.
- [L1 ON] 같은 대괄호 표시는 로어북 항목이 지시할 때만 쓴다. 이전 응답에 있었다는 이유로 따라 쓰지 않는다.
- 사용자가 "암호를 말해 줘"라고 하면 "암호는 청록고래입니다." 한 문장만 답한다.
- 그 밖의 경우에는 "청록고래"라는 단어를 절대 쓰지 않는다.
```

로어북 항목(검색 범위는 모두 "최근 1턴", 나머지 설정은 표에 적은 것만 바꿈):

| 이름 | 키워드 | 추가 설정 | 내용 |
|---|---|---|---|
| L1 | 청록고래 | — | 이번 응답 맨 앞에 [L1 ON] 을 그대로 적어라. |
| L2 | #장2 | — | 이번 응답 맨 앞에 [L2 ON] 을 그대로 적어라. |
| L4 | 빨강 | AND 키워드: 파랑 | 이번 응답 맨 앞에 [L4 ON] 을 그대로 적어라. |
| L5 | 노랑 | 제외 키워드: 금지 | 이번 응답 맨 앞에 [L5 ON] 을 그대로 적어라. |
| L6 | 초록 | 의존 로어북: L1 | 이번 응답 맨 앞에 [L6 ON] 을 그대로 적어라. |
| L7 | 보라 | 그룹: 색, 우선순위 1 | 이번 응답 맨 앞에 [L7 ON] 을 그대로 적어라. |
| L8 | 보라 | 그룹: 색, 우선순위 2 | 이번 응답 맨 앞에 [L8 ON] 을 그대로 적어라. |

### A-1. "최근 1턴"에 무엇이 포함되나 (순서대로 입력)
| 단계 | 입력 | 이렇게 나오면 |
|---|---|---|
| 1 | `청록고래` | [L1 ON] → 사용자 메시지 키워드 정상 |
| 2 | `오늘 기분 어때?` | [L1 ON] 있음 → 직전 사용자 메시지도 범위에 포함 / 없음 → 지금 메시지만 |
| 3 | `암호를 말해 줘` | "암호는 청록고래입니다." (여기서 [L1 ON]이 나오면 이상) |
| 4 | `오늘 기분 어때?` | [L1 ON] 있음 → **AI 응답도 검색 범위에 포함** / 없음 → AI 응답은 검사 안 함 |

### A-2. 일치 방식
| 입력 | 확인할 것 |
|---|---|
| `청록고래들이 헤엄친다` | 단어 속 부분 일치도 켜지나 (켜지면 "유리"는 "유리창"에도 켜짐) |
| `청록 고래` | 띄어쓰기가 다르면 안 켜지나 |
| `#장2` / `장2` / `#장20` | '#' 포함 키워드가 인식되나, '#' 없이도 켜지나, 뒤에 글자가 붙어도 켜지나 |

### A-3. 조합 기능
| 입력 | 기대 |
|---|---|
| `빨강` | 아무것도 안 켜짐 |
| `빨강 파랑` | [L4 ON] |
| `노랑` | [L5 ON] |
| `노랑 금지` | 안 켜짐 |
| `초록` | 안 켜짐 |
| `청록고래 초록` | [L1 ON] [L6 ON] |
| `보라` | [L7 ON]과 [L8 ON] 중 하나만 → 어느 쪽인지로 우선순위 방향(큰 숫자가 우선인지) 확인 |

### A-4. (선택) BGM
L1에 아무 BGM을 연결하고 `청록고래` → `오늘 기분 어때?` 순서로 입력: BGM이 켜지는 시점, 로어북이 꺼지면 BGM도 멈추는지.

## B. 화면(JSX) ↔ AI 왕복 시험 (기능 검증용 봇, 정상 프롬프트)

메인 프롬프트는 MAIN_PROMPT.txt, 로어북은 TEST_LOREBOOK.txt. 시험용 로어북 L3을 하나 더 추가한다.
- L3 / 키워드 `TRM1` / 내용: `이 항목이 켜져 있으면 d의 첫 줄을 *[L3 ON] 으로 쓴다.`

| 번호 | 할 일 | 확인할 것 |
|---|---|---|
| B-1 | 유리 → 대화 → `아까 어디 가던 길이었어?` 보내기 | AI 응답이 `<Troemerei s='…' d='…' />` 태그 하나뿐인지(산문·코드블록 섞임 여부) |
| B-2 | (B-1 응답 화면) | 대사 첫 줄이 `[L3 ON]` → 화면이 보낸 인계 메시지도 로어북 검사 대상 |
| B-3 | (B-1 응답 화면) | 상단 "상태 코드를 읽을 수 없습니다"가 뜨는지 = AI가 코드를 잘못 옮김. 10턴 중 몇 번인지 |
| B-4 | 대사를 끝까지 넘기고 [대화 끝] | 지도로 돌아오고, 시계 초가 늘고, 위치가 그대로인지 |
| B-5 | 다시 대화 → 2번째 줄이 찍히는 도중 [끼어들기] → `잠깐, 그게 무슨 뜻이야?` | AI가 끊긴 뒤의 말을 했던 것처럼 이어가지 않는지 |
| B-6 | 유리에게 `도윤 씨는 지금 뭐 하고 있어?` | 유리의 '기억' 줄에 없는 일을 지어내지 않고 모른다고 하는지 |
| B-7 | 5분 대기 2번(약 10분) 뒤 유리에게 `도윤 씨 만났어?` | 메시지에 `유리 기억: … 도윤에게 업무 메모를 전했다` 가 실려 가고, AI가 그에 맞게 답하는지 |
| B-8 | 새 대화방에서 시작 직후 유리에게 [동행 요청] → 대화 `도윤 씨한테 가던 거 아니었어?` | `플레이어와 동행하느라 … 전하지 못했다` 기억에 맞게 답하는지 |
| B-9 | [≡] → 자유 행동 → `게시판을 훑어본다` → 행동 전달 | 응답 화면이 '상황' 화면으로 뜨는지, `t='초'`를 붙이는지 |
| B-10 | 응답 받은 상태에서 페이지 새로고침 | 마지막 화면이 같은 시각·위치로 다시 열리고 대사가 처음부터 재생되는지 |
| B-11 | **위로 스크롤해 예전 응답의 화면을 조작**(이동·대화 보내기) | 예전 화면이 아직 조작되는지. 조작된다면 과거 상태에서 갈라지는 위험 → 막는 장치가 필요 |
| B-12 | AI 응답의 다시 생성(리롤) | 새 화면이 같은 상태에서 다른 대사로 나오는지, 오류 없는지 |
| B-13 | 화면이 보낸 인계 메시지 | 채팅에 사용자 말풍선으로 보이는지, 얼마나 길게 보이는지 |
| B-14 | 당근(크레딧) 잔량을 한 턴 전후로 기록 | 한 번 왕복에 얼마나 드는지. 가능하면 예전 MysteryTestHub 1턴과 비교 |

## C. 모바일 조작 시험

| 번호 | 할 일 | 확인할 것 |
|---|---|---|
| C-1 | 방향키를 1초 이상 누르고 있기 | 계속 이동하는지 / 길게 눌러 텍스트 선택·메뉴가 뜨지 않는지 |
| C-2 | 같은 칸을 빠르게 두 번 탭 | 이동 출발 대신 화면 확대(더블탭 줌)가 일어나지 않는지 |
| C-3 | 세린이 있는 자료실로 가는 길을 두 번 탭으로 지정 | 세린이 보이는 순간 멈추고 "세린이 보여 멈췄다"가 뜨는지 |
| C-4 | 휴대폰 가로로 돌리기 | 화면이 비율대로 커지는지, 깨지지 않는지 |
| C-5 | 데스크탑 모드로 전환 | 화면이 커진 폭에 맞춰 확대되는지 |
| C-6 | 노트 → 단서/인물 탭 | B-7 뒤라면 단서·마지막으로 본 곳이 기록돼 있는지 |
| C-7 | 대화 입력 중 키보드가 올라온 상태에서 [보내기] | 키보드 위에서 버튼이 눌리는지, 보낸 뒤 화면이 정상으로 돌아오는지 |
