# 조각 쓰는 법 (좌표는 48px 칸 단위, 시트 이름은 파일 이름에서 .png 뺀 것)
#   in 시트 x y          자동 타일(A1·A2) 블록의 '속'(가장자리 없는 칸). x y = 블록 왼쪽 위 칸
#   auto 시트 x y        자동 타일을 이웃에 맞춰 가장자리까지(지형 줄에서만)
#   a3 시트 x y          A3(지붕) 블록의 속
#   face 시트 x y        A4 벽면(위·아래 가장자리 붙임). x y = 벽면 블록 왼쪽 위 칸
#   tile 시트 x y [w h]  그대로 잘라 쓰기
#   cliff 시트 x y       A4 벼랑(지형 ^ |): 윗면은 자동 타일, 아래가 낮은 땅이면 바위 면
#   color #rrggbb        단색
#   여러 개를 + 로 이으면 차례로 겹친다(바닥 + 덧그림)
# object 줄 끝 옵션: fit(덩어리 폭에 맞춰 늘이고 줄임) · repeat(덩어리의 칸마다 반복) · span(왼쪽 끝·가운데 반복·오른쪽 끝으로 늘임) · up=N(위로 N칸 솟음) · draw 이름(직접 그림)
