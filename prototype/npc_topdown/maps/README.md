# 글자 지도 (maps/)

장마다 폴더 하나(`maps/ch1/`), 층마다 파일 하나. 파일 이름 앞 숫자 순서대로 위에서 아래로 쌓인다(층 사이 벽 2줄).
고친 뒤: `python3 tools/build_ch1_map.py` → `src/world_ch1.json`, `python3 tools/render_map_preview.py` → `docs/plan/maps/*.png`.
오류(방 사각형 겹침·짝 없는 계단·모르는 글자 등)는 빌드할 때 줄 번호 대신 좌표로 알려 준다.

## 칸 글자
| 글자 | 뜻 | 걷기 | 시야 |
|---|---|---|---|
| `A`~`Z` | 방(@rooms에 이름). 같은 글자 칸들의 테두리 사각형이 그 방 | O | O |
| `a`~`z`, `0`~`9` | 표시(@marks) — 조사 지점·계단·숨은 공간·막는 칸 | 종류별 | O |
| `+` | 통로(방 밖 문 칸) | O | O |
| `#` | 벽 | X | X |
| `^` | 바위 | X | X |
| `\|` | 절벽(내려다볼 수 있음) | X | O |
| `~` | 바다 | X | O |
| `%` | 수영장 물 | X | O |
| `=` | 건물(밖에서 본 호텔) | X | X |
| `*` | 가구·물건 몸체. 3칸 안의 가장 가까운 조사 지점에 딸린다 | X | X |

방 사각형 안에 막힌 칸(`# ^ ~ * …`)이나 표시는 있어도 되지만, **다른 방 글자는 안 된다.**

## 머리말
- `@level 이름` — 층 이름(필수). 팔찌 위치 조회의 층 지도 이름으로도 쓰인다.
- `@pad ~` — 줄이 짧을 때 채울 글자(기본 `#`).
- `@tide 2일 02:00~04:40, 2일 14:20~17:00` — 썰물 시간대. `tide` 방은 이때만 걸을 수 있다.
- `@sight b m 설명` — 미리보기에 점선으로 그리는 시선(게임 판정은 테스트가 따로 확인).
- `@note 설명` — 미리보기 메모.

## @rooms
`T 갯바위 #34403c tide` — 글자, 이름, (색), (`tide` = 물때 칸).

## @marks
- `f fountain 분수 ⛲` — 조사 지점: 아이디, 이름, 아이콘. 그 칸은 걸을 수 있다.
- `u link 계단(1층↔2층)` — 연결. 같은 이름이 두 칸(다른 층이어도 됨)에 있어야 한다. `off=플래그`면 그 플래그가 켜질 때 끊긴다(밧줄 사다리).
- `x secret wine_gap flag=secret_wine | 문장` — 숨은 공간 벽. 한쪽은 방, 반대쪽은 틈 칸(조사 지점 등)이어야 한다.
- `g guard court open=… warn=a,b over=… who=지배인 area=재판장 앞 | 대사1 | 대사2 | 대사3` — 막는 칸(같은 글자 칸 모두).

## 시야 약속 (test/test.cjs가 확인)
- 선착장 끝 → 바다 건너 바위벽 밑이 보인다(오딜의 사다리 목격).
- 산책로 벤치 → 이끼 비탈 입구는 보이고, 바다 쪽 바위벽·바위틈은 안 보인다(바룬·스즈네).
- 바위 끝 → 바위틈이 내려다보인다(수색대 발견).
- 바위 해안·해안 산책로·해변·이끼 비탈·앞마당 어디서도 바위틈·바위벽 밑은 안 보인다.
