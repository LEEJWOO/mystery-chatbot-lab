# 탑다운 시험판 v1.0 (TRM1)

《몽환의 트로이메라이》의 2D 탑다운 NPC 엔진에 **턴 이어받기 + 상태 압축**을 넣은 시험판이다.
인물(유리·도윤·세린·태수)과 맵은 동작 확인용이며 본편 설정이 아니다.

## v0.9 → v1.0 바뀐 점 (정합성 + 재판 시제품)
- **증언(k)은 실제로 들은 뒤에만**: `k='기억K3R8@3'`(원본 3번째 줄에서 말함). 대화 끝(=끝까지 들음)이면 전부, 끼어들면 끊긴 위치 이전 줄의 증언만 단서가 된다. 줄 번호가 없으면 마지막 줄 기준.
- **끼어들기 위치는 원본 줄 기준**: 화면 페이지가 나뉘어도 `cut=원본줄/원본전체:그 줄 안 글자 수`.
- **대화 끝 버튼**: 다 읽기 전에는 「넘기고 닫기」(= 상대 말을 끝까지 들은 것으로 처리).
- **기억 코드 고정**: `facts[].code`(영문·숫자 4자, 예: 기억K3R8). 사실 순서가 바뀌어도 코드 불변, 추측하기 어려움.
- **시선 차단**: 같은 방·거리 안이어도 벽·키 큰 가구가 직선을 막으면 안 보인다(`props[].low`인 낮은 가구는 안 막음). 목격·로그·장면 모두 적용.
- **목격 장면 위치 판정**: `near`(랜드마크)·`radius`(칸) — 방이 아니라 '그 근처에 있었는가'.
- **세계 지문 확대**: 공지·사건·갈래·장면·재판·물건 조건·속도 등 판정 규칙 전부 + `dataVersion`. 설명 문구만 바뀐 경우는 호환.
- **화면 밖 대화(f)에 상태 코드가 없으면** 새 세계로 시작하지 않고 복원 화면.
- **재판 시제품**(설정 › 재판 시제품 시작): 개정(대본) → 증언에 증거 제시 → AI 반론 1회(R, 사건 코드로 판정) → 꿈 조각 잇기 → 투표 → 폐정. 재판 전용 체력(◆), 0이 되면 바쿠가 그 단계를 되감음(진엔딩 플래그면 되감기 없음). 재판 중 시간 정지. 상태 코드에 재판 진행 저장(형식 6).

## v0.8 → v0.9 바뀐 점 (먼저 말 걸기·현장 인물·그림 정리)
- **먼저 말 걸기**: 일정에 `targetPlayer: true` 과제를 넣으면 그 시간에 플레이어를 찾아와 곁에서 기다린다(시험: 태수 09:40~). 「돌아본다」를 누르면 바로 인계되고 `상황:` 줄(먼저 말을 걸었음, 휴식 중이었다면 잠들어 있었음)이 붙는다. 「나중에」는 돌아감, 응답이 없으면 기다리다 돌아감. 휴식은 이때 멈춘다.
- **A·P에 현장 인물**: 추리 제시·자유 행동 인계에 `함께 있는 사람: 이름(하던 일)…` 줄. 없으면 `없음`.
- **그림 정리**: 유리↔세린 그림 교체(활발=분홍 긴 머리, 조용=은발 단발), 도윤(흰 코트)·태수(크림 후드) 대화 그림 추가. 탐색 도트도 같은 외형(치마·스타킹·코트 앞트임·후드)으로 다시 그림.
- 못 연 메모·장면에 힌트를 표시하지 않음(??? 만).

## v0.7 → v0.8 바뀐 점 (수첩·목격·끼임 탈출)
- **인물 수첩**: 인물 카드(그림·공개 프로필·메모 n/m). 메모는 조건(`talked` 말 걸어 봄 · `seen` 본 적 있음 · `fact` 그 사실을 앎 · `scene` 그 장면을 봄 · `flag`)이 맞으면 붙고, 아니면 ??? + 힌트. 못 만난 인물은 실루엣.
- **목격 장면(앨범)**: 목격 기록을 글로 쌓지 않고, `world.scenes`에 정해 둔 장면만 해금(사실을 직접 봄, 또는 그 인물이 그 방에 그 시간대에 있는 걸 봄). 증언으로 들은 건 해금 안 함. 그림(`img`)이 없으면 인물 그림으로 대체. 상태 코드에는 해금 시각만(형식 5).
- **끼임 탈출**: 사방이 막혔을 때만 가장 가까운 빠져나갈 빈칸으로(시간 0). 객실 귀환(순간이동)은 모든 루트에서 삭제.
- 노트 탭: 수첩·목격·증거·단서·휴식·설정(기록은 설정 안으로).

## v0.6 → v0.7 바뀐 점 (방 화면·물건·휴식)
- **방 하나 = 한 화면**: 지금 방(벽 포함)만 잘라 보여 주고, 다른 방으로 넘어가면 짧게 암전. 작은 방은 가운데, 큰 방은 방 안에서만 카메라 이동. 문 칸에서는 직전 방 유지. 내부 계산은 층 격자 그대로.
- **물건 등장 조건(기능 확인용 임시)**: `world.items[{id,name,at(랜드마크),from('1일 09:30'),flag,desc}]`. 조건 전에는 없고, 「조사」(20초)로 찾으면 소지품·증거 카드(발견 시각·장소). 상태 코드에 발견 시각 보존(형식 4).
- **휴식(시간 건너뛰기)**: 다음 시간대까지 / 자고 아침으로 / 시각 지정(시·10분 단위). 공지 시각, 누군가 곁에 멈춰 섬, 보이는 사건에서 멈춘다. 미리보기는 공지만(남의 계획은 안 보임). 최대 2일.
- **시간대 갈래 표식**: 머리말에 `#1일아침A`(새벽은 전날 밤). `world.branches`의 조건이 맞으면 B·C…
- **공지**: `world.notices`(매일 반복). 평소 안내 줄에 다음 공지 표시.

## v0.5 → v0.6 바뀐 점 (탐색 화면 그래픽)
- **전체 맵 이미지**: `tools/pixelart.py`가 world.json(rows·props·decor·floors)으로 도트 맵을 그린다(칸 18px 원본 ×2). 가구는 `map.props`, 바닥 장식은 `map.decor`, 방별 바닥은 `map.floors`. 랜드마크는 앞 칸이 서는 자리이고 `hit` 칸(가구)을 눌러도 선택된다.
- **걷기 스프라이트**: 하·상·좌·우를 각각 따로(좌우 반전 안 씀), 방향마다 정지 1장 + 걷기 여러 장. 장수는 주소 표 `sprites.dirs`를 따르므로 자유(시험 그림은 걷기 4장). 한 칸 이동 동안 걷기 그림을 절반씩 넘겨 두 칸에 한 주기. 우 그림이 없는 시트는 좌를 뒤집어 대체. 칸 사이 이동·카메라는 0.18초 부드럽게.
- 인물 머리(한 칸 위)를 눌러도 선택, 이름표·그림자·선택 표시, HUD·방향 패드·메뉴 디자인 정리.
- 그림이 없으면 예전 도형 화면으로 자동 대체.

## v0.4 → v0.5 바뀐 점
- **그림 레이어 조립**: 장소 배경 + 인물 몸 + 표정 조각. `tools/assets.py`가 표정만 다른 통 이미지들을 비교해 달라진 부분만 잘라 조각으로 만든다(차분 자동 추출). 파일 이름은 내용 해시, 공개 위치는 저장소 `assets/pub/`(외부 호스팅). 원본은 `assets_src/`(커밋 안 함).
- **표정 선택**: AI가 쓴 `이름(표정)`을 동의어로 준비된 표정에 맞춘다(없으면 기본 표정). 서술 줄은 직전 화자 유지, 그림 없는 인물은 실루엣.
- **증언(k)**: 대상이 말한 기억 코드를 적으면, 대상이 정말 아는 일일 때만 플레이어 단서에 「○○의 증언」으로 기록(사실로 확정하지 않음).
- **기억 코드**: 인계 메시지에 대상 기억을 `기억001직` 같은 코드로만 보낸다. 내용은 로어북(`dist/MEMORY_LOREBOOK.txt`, 플레이어에게 안 보임).
- **화면 밖 대화(f)**: UUMMAI 입력창 대화의 응답은 시간·사건을 바꾸지 않고 마지막 전송 시점에서 이어진다고 알린다.
- **만남 성립 조건**: 만나는 동안 상대도 붙잡고, 끝날 때 곁에 없으면(동행으로 데려가는 등) 무산 → 다시 찾아간다. 로그 공개도 시야 판정과 같은 기준.
- **긴 대사**: 3줄을 넘는 발화는 같은 화자의 여러 페이지로 나눈다.
- **끼어들기 시간**: 내 말은 전부, 상대 대사는 가장 멀리 읽은 위치까지. 되감은 뒤 끼어들어도 이미 읽은 부분은 말한 것으로 처리. 행동 메뉴도 같은 기준.
- **사건 코드**: 끼어들기(I)도 일반 대화(T)처럼 인정.
- **전송 실패**: 전송 함수가 없으면 보낼 문장을 직접 보여 주고, 비동기 실패면 잠금을 풀고 원래 상태로 돌린다.
- **화면 축소 순환 수정(v0.4.1)**, 진엔딩 표식 `#진루트`.
- 상태 코드 형식 3(기억 역할 확장). 이전 코드는 읽지 않는다.

## v0.3 → v0.4 바뀐 점
- **빠른 시간 계산**: 1초씩 돌지 않고 다음 예정 행동 시각으로 건너뛴다. 1초 방식과 결과가 완전히 같음을 테스트로 확인(약 2.5일 분량, 5개 시나리오). 하루 건너뛰기 약 0.15초 → UUMMAI 5초 실행 제한에 여유.
- **사건 코드(e)**: AI가 태그에 `e='TRUE'`를 붙이면 화면이 세계 데이터의 조건(대화 종류·대상 인물·중복)을 검사한 뒤에만 플래그로 기록. 시험 맵에서는 유리와의 대화(T)만 인정.
- **로어북 표식**: 매 인계 머리말 끝에 `#장1`, 진엔딩 플래그가 있으면 `#진루트`를 자동으로 붙인다(로어북 키워드는 # 없이 `장1`·`진루트`. 플랫폼이 키워드의 #을 지운다. 검색 범위 '현재 유저 입력만' 항목용).
- **이미지 ID 표**: 화면 코드는 `yuri_default` 같은 ID만 쓰고, 빌드할 때 `src/assets.<플랫폼>.json`(기본 uummai)의 주소 표를 끼워 넣는다. 대화 화면은 지금 말하는 인물 → 대화 상대 순으로 그림을 찾아 화면 전체에 깐다. 못 불러오면 임시 그림.
- **TRM1 아닌 메시지(자체 입력창)**: AI가 최근 상태 코드로 태그를 다시 붙이고 장면을 d에 쓰면, 대상 없는 '상황' 화면으로 이어진다.
- 메인 프롬프트 정식화: 플레이어 인물(페르소나) 규칙, 자체 입력창 처리, 표식·운영 단어·이미지 출력 금지.

## v0.2 → v0.3 바뀐 점
- **모바일 세로 2:3(360×540) 한 화면.** 휴대폰에서 UUMMAI가 내주는 폭(약 360px)과 높이(약 540px)에 맞춤. 폭이 다르면 비율을 유지한 채 확대·축소.
- **탐색 화면 / 1:1 대화 화면 분리.** 인물·물건을 누르면 2×2 행동 메뉴(대화·동행 요청·동행 종료·관찰), [대화]를 고르면 1:1 화면(대사 상자 + JSX 입력칸 + 행동 메뉴 + `*` `"` 입력 버튼).
- **이동**: 방향키(누르고 있으면 연속) + 같은 방 안에서만 '경로·시간 미리보기 후 한 번 더 탭'으로 출발. 새 인물이 보이면 자동 정지.
- **방 단위 시야**: 지금 있는 방만 보이고 다른 방은 어둡게, 보이는 인물만 표시. 상단 [노트]에 단서·인물(마지막으로 본 곳)·기록, [≡]에 대기·자유 행동·상태 코드.
- **인물별 기억**: 사건 당사자는 '직접', 같은 방 근처 사람은 '목격'으로 기억. 대화 인계에 대상의 상태·기억과 내 단서를 화면이 실제 상태로 만들어 보낸다(AI가 추측하지 않음).
- **세계 지문**: 맵·일정·후속 규칙·사실 정의가 바뀌면 옛 상태 코드를 명확한 오류로 거부(조용히 처음부터 시작하지 않고 복원 화면을 띄움).
- **날짜 넘김**: 일정 시각을 '그날 기준'으로 비교해 자정 뒤에도 다음 날 일정이 재개.
- **연기/취소 구분**: 일정마다 `onAccompany: cancel | postpone`.
- **대화 시간은 화면이 계산**: (사용자 글자 수 + 응답 글자 수) ÷ 6 + 4초. AI는 `t`를 쓰지 않는다(자유 행동 P만 예외).
- 움직이지 않는 지도 층은 한 번만 만들어 다시 그리지 않음.

## v0.1 → v0.2 바뀐 점
- **상태 압축 코덱(`src/codec.js`)**: AI가 매 턴 복사하는 상태를 JSON 약 1,000자 이상 → base64url 약 100~140자로 줄였다. 끝 2바이트 체크섬으로 복사 실수를 잡아낸다.
- **AI 출력 형식 단순화**: `<Troemerei s='상태' t='경과초' d='이름:대사|*서술' />` 태그 하나. 색·속도·크기 같은 연출 기본값은 JSX가 가진다. 산문과 JSON에 같은 대사를 두 번 쓰지 않는다.
- **인계 메시지 단순화**: 한 줄 머리말(`TRM1 T 유리 | 09:00 정원`) + 사용자 입력 + `s=코드`. 맵·오브젝트·시나리오 소개문을 매번 다시 보내지 않는다.
- **대화 화면**: 한 줄씩 출력, 이전/다시 듣기, **끼어들기**(본 위치를 `cut=줄/전체:글자`로만 전달하고 그 뒤는 말하지 않은 것으로 처리, 대화 시간도 본 비율만큼만 반영).
- **시간은 행동할 때만 흐른다**: 실시간 진행 버튼을 없애고, 이동 중·대기·대화 응답 시간만 시계를 움직인다.
- 지도 탭이 이동으로 인식되지 않던 문제(포인터 캡처) 수정.

## UUMMAI 실측 순서 (이어받기 확인용)
1. 컴포넌트 `Troemerei`로 `dist/Troemerei.jsx` 전체를 등록한다.
2. 메인 프롬프트에 `MAIN_PROMPT.txt`, 로어북에 `TEST_LOREBOOK.txt` 항목을 넣는다.
3. 새 대화 시작 → `<Troemerei />`가 화면으로 나오는지.
4. 유리(바로 옆)를 눌러 행동 메뉴 → [대화] → 입력칸을 눌렀을 때 **휴대폰 키보드가 화면을 얼마나 가리는지** 스크린샷.
5. 말 입력 → [보내기]. AI 응답이 **태그 하나**로 오고 대사 화면이 뜨는지, [대화 끝] 후 위치가 보존되고 시간이 흐르는지([≡] 상태 코드나 시각으로 확인).
6. 대사 2번째 줄 도중 [끼어들기] → 입력 → 전달. AI가 끊긴 위치 뒤를 말하지 않은 것으로 다루는지.
7. 페이지를 새로고침해도 마지막 화면이 같은 상태로 다시 열리는지.
8. 상단에 "상태 코드 오류(체크섬 불일치)"가 뜨면 AI가 코드를 잘못 복사한 것이다. 빈도를 기록한다.

## 아직 안 되는 것
본편 인물·사건·단서·재판·시야 판정·여러 맵 연결은 없다. 화면에서 로컬로 진행한 뒤 AI에게 보내지 않은 이동은 새로고침하면 사라진다(마지막으로 받은 태그가 기준).
