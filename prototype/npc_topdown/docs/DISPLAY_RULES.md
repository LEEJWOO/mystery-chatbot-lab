# 스탠딩 그림 표시 규칙 (확정 · 2026-11-26)

1. 같은 인물의 그림(자세·표정 머리·의상 레이어)은 **모두 같은 배율, 같은 위치**로 표시한다. 그림마다 확대·축소·이동하지 않는다.
2. 인물마다 다른 것은 **표시 배율 1개와 y축 값 1개**뿐이다(인물별). 이 두 값은 전 인물 줄 세우기(같은 바닥 기준, 눈대중으로 자연스럽게)로 한 번 정하고 표에 적는다.
3. 키·머리 크기·체격의 차이는 그대로 둔다. 인물끼리 크기를 맞추지 않는다. 실제 키 수치로 픽셀을 계산하지 않는다.
4. 자세·표정이 어긋나 보이면 화면에서 보정하지 않고 그림을 고친다.
5. 이 규칙과 다른 처리(자동 맞춤, 개별 보정 등)는 **하기 전에 반드시 상의**한다.

참고: v2.0 시험판의 '눈 기준 자동 확대·이동'(커밋 56e2b9a 이후)은 이 규칙 위반이며, 새 그림 체계에서는 쓰지 않는다.
