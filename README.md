# 《몽환의 트로이메라이》 — UUMMAI 추리 챗봇 개발 저장소

이 저장소는 **UUMMAI 플랫폼에서 서비스할 인터랙티브 추리 챗봇 《몽환의 트로이메라이》(가칭, 약칭 트로메라)**의 기술 실험과 구현을 관리합니다. **UUMMAI는 플랫폼명이지 작품명이 아닙니다.**

## 현재 방향

- 플레이어가 추리의 주체인 자유 행동형 미스터리 챗봇
- **2D 탑다운 탐색**(목적지 선택과 수동 이동), NPC의 자율 이동·일정·플레이어 개입에 따른 변경
- 하나의 큰 **인라인 메인 스토리**와 자유 대화·예외 행동을 처리하는 아웃라인 진행
- 위치·시간·동선·증거·사건 판정은 결정적인 코드/데이터가 담당하고, LLM은 자유대화와 서사를 담당
- 플레이어는 일반적인 이능력을 선택해 사용하지 않으며, 숨겨진 능력 ‘드림워크’와 정체의 반전이 있다. **스토리 정본은 [STORY.md](STORY.md)** — [미정]으로 표시된 부분은 임의 보충 금지

## 저장소 상태와 참고 자료

- `lab13/`: **구버전의 13차 통합 기술 시험**. 당시의 조사·증거·대화·상태 인계 기능을 검증하는 보관 자료. 현재의 최종 탐색 UI가 아닙니다.
- `assets/`: 이미지 레이어 합성 시험용 자산.
- `.github/workflows/`: 과거 웹/Worker 배포 시험 자동화. 실제 환경에서 재검증 필요.
- `prototype/npc_topdown/`: **현재 작업본.** 2D 탑다운 NPC 엔진 시험판 v0.2(TRM1) — 턴 이어받기, 상태 압축, 대사 끼어들기. UUMMAI 실측 전.
- `STORY.md`: 스토리 정본. `docs/drafts/`: 사용자 승인 전 초안(정본 아님).

## 폐기한 시연·연출

예전 루트의 `arcane_portal.webp` 및 이를 단독으로 보여 주던 WebP/오버레이 페이지는 **임시 기술 시연일 뿐 작품의 필수 기능이나 디자인 기준이 아닙니다.** 따라서 루트 시연 자료는 정리했습니다. 장면 전환이나 문이 열리는 등의 연출은 필요할 때 일반적인 연출 도구로 재설계할 수 있으며, **마법진 모양이나 단독 화면 전환을 요구하지 않습니다.**

## 개발 시 주의

1. 본편 설정·스토리는 별도의 정본 문서에 실제로 저장하고 코드 버전과 함께 관리합니다. 대화나 모델 기억만을 백업으로 취급하지 않습니다.
2. 옛 `lab13`의 1인칭/격자 탐색을 정식 UI로 되살리지 않습니다. 재사용할 것은 상태 관리, 규칙 검증, 증거·대화·렌더링의 일반 원칙입니다.
3. GitHub의 현재 코드와 새 대화의 산출물이 같다고 가정하지 않습니다. 커밋 전에 최신 파일과 기존 작업을 확인합니다.
4. 독립 브라우저 테스트, UUMMAI 실제 실행, Cloudflare Worker 배포를 각각 별도 검증 상태로 기록합니다.
