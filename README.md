# 원본 그림 보관 (몽환의 트로이메라이 · 시험판)
그림 담당(동업자)이 만든 원본 PNG·마스크 보관용 브랜치. 화면에서 쓰는 변환본(webp)은 `troemerei/prototype-v0.2` 브랜치 `assets/pub/`에 있다.
- `chars/basic-costumes-144/` 6명 기본 의상 1024px 원본 144장 + 인페인트 마스크 120개 (영애 생각·의심은 교체본 반영)
- `chars/mei-pose-revision-21/` 메이벨 생각·지목·팔짱 재생성본(자세 3 + 표정 9 + 마스크 9) — 위 세트의 영애 같은 파일을 대체
- `bg-items/` 방 배경 5장(1216×832) · 증거품 8장(1024px)
- `sprites/` 맵 보행 도트 6장(108×216, 프레임 36×54, 3열×4방향)
- `pilots/` 시험 생성본(라운지 배경 초안, 클라라 목격 장면 초안 — 채팅 첨부본이라 원본보다 작을 수 있음)
- `docs/persona-6-test-cast.txt` 시험 인물 6명 성격·비밀 원고
노출이 심하거나 잔인한 그림은 이 공개 브랜치에 올리지 않는다(수영복 시험본 등 제외).
