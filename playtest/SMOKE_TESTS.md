- 화면 가로 드래그 후 45° 정렬; 세로 드래그로 시야 위아래 전환; 회전 시간 비용 0초
- `전진` 버튼 1회로 한 칸만 이동; 벽·인물·닫힌 문에 막히면 시간 비용 0초

- 안내 게시판 읽기: 같은 고정 문구, LLM 호출 없음
- 서랍 비밀번호 `0912` 입력 → 열쇠 등장 → 획득 → 자료실 문 열기
- 자료실 문은 열쇠 없이 열리지 않고 열쇠가 있으면 열리는지 확인
- 관측 기록·소지품·시간·문 상태가 JSON 체크포인트에 유지되는지 확인
- `기록` 메뉴에서 자유 추리 제시 → AI가 대사·시간을 반영해 탐색으로 복귀
- 플레이 중 09:14 이후 직원의 위치 갱신, 09:15 이후 폐관 안내 이벤트가 한 번만 기록되는지 확인
- `저장` 메뉴에서 로컬 체크포인트 복원; 중복 `reply.id` 시간 이중 청구 금지
