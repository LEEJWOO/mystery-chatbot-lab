## UUMMAI 로어북 기능
키워드(20자) · AND(5) · 제외(5) · 검색 범위(현재 유저 입력 / 최근 1~5턴 / 전체) · 의존 로어북(3) · 그룹+우선순위 · 상시 활성화.
본문에서 `#`로 절을 나누면 모델이 더 잘 따른다. `{{user}}`·`{{char}}` 치환 있음. 접는 칸·코드블록 표시는 미확인이라 쓰지 않는다.
쓰는 법은 `docs/lore/CAST_v2.txt` 머리말 참고.

## 압축 표기 규칙
- 압축 언어는 한국어. 이름·대사 예시·조건·말투 단어는 한국어 원문 그대로. 로마자 이름 금지(태그 이름 오류).
- 상태는 高·低(신뢰高 = 신뢰·깊은 신뢰 등, 본문 §7 정의). 변화는 +1·−1. ↑·↓는 쓰지 않는다.
- →는 '조건→결과'에만. 한 줄에 규칙 하나. ∧는 괄호 안에서만: `옆 사람 다칠 듯→(짧은 반말 ∧ 체면 무시)→귀 빨개짐`. 서로 다른 조건은 줄을 나눈다.
- ¬는 '하지 않음'. 「상대」「누군가」를 U로 바꾸지 않는다(적용 대상이 좁아짐).
- 규칙 줄은 명사형(~함·~음) 허용. 대사 예시·좋은 예/나쁜 예는 원문 문장 그대로(문체가 출력에 옮음).
- 조건부 문장(「공개 전에는」 등)의 조건을 지우지 않는다. 한 인물 = 한 로어북 항목. 설정 칸(키워드·AND·제외·의존)은 압축 대상이 아니다.

## 압축 단계 (확정할 때)
1. 원문(이 저장소의 읽기 쉬운 판)을 고친다. 원문이 기준이다.
2. 확정 시 원문에서 압축본을 만든다: 반복 주어 생략, 기호 치환(→, /, ·), 자주 나오는 말만 짧은 약어로 치환하고 맨 위에 약어표를 둔다.
3. 압축은 이행률을 해치지 않는 선까지만. 예시 문장·판정 조건·출력 형식은 압축하지 않는다.
4. 같은 시험 대화로 원문과 압축본을 비교해 결과가 같은지 확인한 뒤 올린다.
