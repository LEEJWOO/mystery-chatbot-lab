# 1장 재판 장면 초안

## 반론 · 팔찌가 알려 준 시각 (초안 2026-11-28, 사용자 작성 → 표기 정리)
- 배치: 해제 기록을 읽은 직후. 반론자 메이벨(가정).
- 플레이어 증거: 저스틴의 팔찌 기록 — 18:40 '해제 감지'.
- 메이벨의 세 문단
  1. "팔찌가 풀린 시각은 여섯 시 사십 분. 이건 우리 모두 같은 기록을 보고 있지요?"
  2. "다시 차지 않으면 십 분 뒤에 처형이에요. 지배인이 우리에게 직접 읽어 준 규칙이잖아요."
  3. "그러니 저스틴이 여섯 시 오십 분에 처형됐다는 것까지, 이 기록으로 확인된 셈이에요."
- 정답: ③ + 팔찌 기록 → 자유 입력. 질문 "메이벨이 기록에서 읽은 사실과, 규칙을 보고 짐작한 일을 짚어 보자."
- 인정 예: "기록된 건 팔찌를 푼 시각뿐이야. 십 분을 더하면 기한은 알 수 있어도 실제 집행 여부는 지배인에게 물어야 해."
- 판정: '해제와 실제 집행은 별개'면 통과. 특정 시각·사인·바룬 이름은 요구하지 않음.
- 틀린 문단/증거: 체력 감소 → 메이벨 "어느 대목이 그 증거와 어긋난다는 거죠?" → 독백 '같은 기록을 읽었는데, 메이벨은 거기서 어디까지 알아냈다는 거지?' → 세 문단 재생.
- 설명 부족("십 분 뒤잖아"): 메이벨 "저도 십 분을 더했어요. 그럼 우리 둘의 계산은 같은데요?"(AI가 실제 주장에 맞춰) → 독백 '시각 계산에는 이견이 없어. 확인해야 하는 건 그 시각에 무슨 일이 있었느냐야.' → 같은 입력 창.
- 성공: 하지메 "지배인. 열여덟 시 오십 분에, 저스틴에 대한 해제 벌칙을 집행했어?" / 지배인 "집행하지 않았습니다."
- 이후: 해제 벌칙 사망 배제. 실제 사망 18:47은 작가용 시간표에만.
- 시제품: world_ch1 시험 재판 X1의 10~11단계에 들어가 있음(tools/build_ch1_map.py).
