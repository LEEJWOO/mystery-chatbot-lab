# 인물별 표정 목록 v1 (2026-11-28)

프롬프트 본문은 `EXPRESSION_PROMPTS.txt`. 전체 36종 = 핵심 12 + 추가 24.
AI는 36종 중에서 고르고, 그 인물에게 그림이 없으면 화면이 대체 표정으로 바꿔 보여 준다(아래 대체표).

## 만드는 순서
1. **핵심 12종 — 전원 필수**: 기본·미소·웃음·의심·놀람·곤란·부끄러움·불만·슬픔·격노·패닉·하라구로
2. **데스게임 공통 4종 — 전원 권장**: 진지·충격·공포·절망 (시신 발견·재판·처형 장면에 모두가 쓰임)
3. **인물별 맞춤** — 아래 표
4. **나머지** — 여유가 생기면(전원 36종 = 396장)

1~3까지 하면 인물당 약 22장, 11명 약 240장.

## 인물 성격을 한 줄 더하는 예 (선택)
같은 표정에 아래 줄을 하나 더 붙이면 인물마다 차이가 난다.
- 메이벨 폭소: `1.3::haughty laugh, ojou-sama laugh::,`
- 클라라 노려봄: `1.3::cold elegant glare::,`
- 바룬 진지: `1.3::stoic face::,`
- 프레디 냉소: `1.3::quiet disdain, bored eyes::,`
- 저스틴 의기양양: `1.3::cocky grin, confident athlete::,`

## 대체표 (그림이 없을 때 화면이 보여 줄 표정)
