# 본편 기획 초안 v1 — 무대·12인 명단·1장 사건 뼈대 (2026-11-24)

> 상태: **틀 승인(2026-11-24)** — 다국적 명단·호텔 레브리·12인 명단과 1장 뼈대의 틀·재판까지의 과정·1C 원칙·2장 RIGHT / LEFT. 세부는 계속 다듬는다(직접 플레이 후 수정 가능).
> 전제: 12인(플레이어 + 11명) + 지배인, 3장, 장마다 피해자 1 + 처형 1 → 6명 사망·6명 생존. A는 2장 피해자.

## 1. 무대 — 호텔 레브리(Rêverie, '몽상')

바다 위 작은 섬의 폐업 리조트 호텔. 직원은 없고 지배인 혼자 관리한다(진상: 꿈의 주인). 배는 없다.

| 층 | 방 | 잠금·비고 |
|---|---|---|
| 옥상 | 전망 정원·헬리포트 | 잠김 → 3장에 열림(최종 무대) |
| 3층 | 도서실, 게임룸, 의무실, 스파(사우나), 전망 라운지 | 스파는 2장에 열림 |
| 2층 | 객실 12개(1인 1실), 린넨실, 비상계단 | 객실은 각자 열쇠. 이웃한 두 객실의 욕실 환기구가 이어져 있다(2장 트릭) |
| 1층 | 로비·프런트(공지판), 라운지 바, 레스토랑, 주방(+냉동 창고), 연회장(=재판장) | 연회장은 재판 때만 열림. 지배인실은 늘 잠김(복선) |
| 바깥 | 정원, 수영장 데크, 선착장(빈 보트 창고) | 밤 22시~06시 바깥 출입 금지(규칙) |
| 지하 | 기관실(발전기), 세탁실, 창고 | 기관실은 3장에 열림(정전 트릭) |

- 화면 수: 약 30개. 객실 12개는 한 가지 배치를 좌우 반전해 재사용한다.
- 외국인 참가자끼리 말이 통하는 것도 '이 호텔의 서비스'로 설명한다(꿈의 허용, 복선).

## 2. 게임 규칙(안)

- **졸업:** 누군가를 죽이고 재판에서 들키지 않으면 범인만 호텔을 떠난다(나머지는 처형). 들키면 범인만 처형.
- **참가자 명부:** 첫날 지배인이 각자 자기 능력을 **스스로 신고**하게 해 명부를 만든다. 거짓 신고도 가능하다 → 재판에서 명부와 증거가 부딪친다(구절 짝짓기·진상 결정에 직결).
- **공지:** 아침 8시, 정오, 저녁 7시에 지배인 방송. 밤 22시~06시는 바깥 출입 금지.
- **장마다 동기:** 지배인이 장 시작 때 '숙박 안내'를 하나 덧붙인다.
  - 1장: "이곳의 하루는 바깥의 1년입니다."
  - 2장: "여러분 중 한 분은 이 세계를 끝낼 수 있는 분입니다."
  - 3장: (안) "주인께 닿는 문은 옥상에 있습니다."

## 4. 1장 「첫날 밤의 냉동 창고」 뼈대 (인라인 1A)

**동기:** 하루가 바깥의 1년이다. 도하는 갓 태어난 딸의 첫 몇 해를 놓치는 것을 견디지 못한다.

| 시각 | 일 |
|---|---|
| 1일 09:00 | 각자 객실에서 깨어남. 10:00 로비 집합, 지배인의 규칙 안내와 명부 신고 |
| 1일 오후 | 자유 탐색. 15:00 레오가 선착장에서 물 위 걷기를 시험하지만 파도가 높아 실패. "내일 새벽 바다가 잔잔하면 건너가서 구조를 부르겠다" |
| 1일 19:00 | 도하가 저녁을 차린다. 지배인이 동기를 공지 |
| 1일 21:30 | 도하가 "건너갈 때 가져갈 식량을 챙기자"며 레오를 주방 냉동 창고로 부른다 |
| 1일 21:40 | 살해. 도하는 주방의 무쇠 판을 80℃로 달궈 시신 곁에 두어 체온을 유지한다(살아 있는 생물이 아니라서 가능) |
| 1일 22:00~23:30 | 도하는 라운지 바에서 여럿과 함께 있다 → 알리바이 |
| 2일 07:00 | 아침 준비를 도우러 간 바야르가 발견 → 지배인 방송 → 조사 → 재판 |

**단서(안):**
- 연수의 검시: 체온은 23시 사망을 가리키지만, 경직·시반은 21~22시를 가리킨다.
- 무쇠 판 4장이 주방에서 사라졌다가 린넨 카트에서 발견되고, 판에 열 자국이 있다.
- 냉동 창고 문 안쪽에 긁힌 자국이 있다.
- 미오의 목격: 21시 50분에 도하가 린넨 카트를 밀고 있었다(목격 앨범).
- 명부: 도하의 온도 조작 신고 내용과 열 자국이 맞물린다.
- 에바의 거짓말 맛보기: 도하의 "나는 21시 반에 주방에 없었다"가 짜다.

**미끼:** 바야르가 무게 덜기로 시신을 옮겼다는 의심. 발견자인 데다 무거운 걸 옮기는 모습이 목격된다.

**갈래 후보:**
- **1B (가장 흔할 이탈):** 플레이어가 21시대에 레오와 함께 있어 도하가 혼자 불러내지 못한다 → 새벽 05:30, 레오가 맨발로 선착장 사다리를 내려갈 때 도하가 미리 얼려 둔 사다리에서 미끄러져 익사한다(여름 아침의 서리가 단서). **범인은 같고 수법만 바뀐다** → 2장에 미치는 차이가 작다.
- **1C (확정 원칙):** 플레이어가 두 시도를 모두 막으면 범인은 그대로, 다른 피해자로 바뀐다. 다음 장에서는 「누가 살아 있나」만 달라진다.

## 5. 2장 「RIGHT / LEFT」 (사용자 원안 2026-09-22 사건을 이식, 승인 11-24)

유지할 세 구조: RIGHT(범인이 보여 주고 싶던 증거·결론)와 LEFT(범인이 통제하지 못한 사실)의 대비 / 전반부·후반부의 의미 반전 / 사인 규명과 범인 특정의 분리.

- 무대: 지하 식료품 창고(지배인이 식자재를 드라이아이스로 보관). 2일차부터 창고 정리 **당번제**(당번표 기능이 핵심 자료).
- 피해자 소라(A), 범인 노아, 동기 「세계를 끝낼 분」 공지 + 소라의 「판정 불가」.
- 실제: 노아가 성대모사(연수 목소리)로 당번 교대를 부탁해 소라를 혼자 창고로 → 환기를 꺼 둠 → 바닥에 앉아 스케치하던 소라가 이산화탄소로 쓰러짐(주변에 아무도 없었다는 증언은 사실) → 노아가 사후에 꼬치로 목에 상처, 바닷물을 뿌리고 도하가 남긴 얼음 틀을 눈에 띄게 둠, 꼬치는 빈 드라이아이스 상자 속 → 미오의 당번도 같은 수법으로 옮겨 얼음칼 가설이 미오를 가리키게 함.

| 증거 | RIGHT(전반부) | LEFT(후반부) |
|---|---|---|
| 목의 상처, 흉기 없음 | 녹아 없어진 얼음칼 | 사후 상처, 꼬치는 드라이아이스 상자 속 |
| 염분 | 바닷물 얼음칼이 녹은 흔적 | 일부러 뿌린 바닷물 |
| 출혈이 적음(검시) | 차가운 칼에 혈관 수축 | 이미 심장이 멈춘 뒤 |
| 함께 있다 나온 사람은 멀쩡함 | 공기 문제가 아니다 | 그는 서 있었고(이산화탄소는 바닥에 고임) 소라는 앉아 있었다 |
| 소라의 스케치북 | 의미 없는 낙서 | 마지막 선이 흐트러짐(산소 부족), 그린 시각 |

- 범인 특정(사인과 별개): 당번 교대 요청이 연수 목소리로 왔지만 그 시각 연수는 의무실에서 엘리와 함께(엇갈린 증언) / 진의 잔향(창고 선반이 연수 목소리를 들음) / 명부의 「절대음감」 거짓 신고(구절 짝짓기) / 노아의 말실수(공개되지 않은 「차갑고 숨 막히는 창고」).
- 공정성: 전반부에 플레이어가 맞추는 것은 「증거가 말하는 사실」뿐이고 얼음칼 결론은 NPC가 내린다(동의·이의 가능). LEFT 단서를 이미 가진 플레이어는 결론 지점에서 「다른 설명」을 증거로 대면 전반부를 짧게 건너뛰고 대사로 보상(근거 없으면 「근거는?」). 구절 짝짓기를 전·후반에 같은 자료로 두 번(후반엔 짝이 다르게), 진상 결정은 사인·성격·책임자를 따로.
- 2B: 당번 시각에 플레이어가 소라와 함께 있거나 창고 문을 열어 두면 → 노아는 객실 환기구 + 소라 목소리로 사망 시각을 속이는 수법으로(같은 범인).
- 진엔딩 재현: 연수의 잠의 손으로 소라를 쓰러진 것처럼.
- 1장 온도 조작과의 겹침은 의도된 메아리로 둔다(1장에서 익힌 감각이 2장의 함정).

## 5-1. 3장 한 줄 뼈대
- 기관실·옥상이 열림 → 하린이 상담으로 모은 이야기에서 이곳이 「누군가의 꿈」이라는 결론에 닿는다 → 거짓말을 잡을 수 있는 에바를 정전 중에 살해, 목격자에게 가짜 장면을 새긴다. 단서는 소리·색이 없는 기억(기억 현상). 재판의 끝이 지배인에 대한 의심으로. *동기 세부 미정.*

## 6. 재판까지의 과정 (확정 11-24, 직접 플레이 후 수정 가능)

**공통 뼈대 — 장마다 바꾸는 건 발견 방식과 조사 시간뿐:**

1. **사건(자유 시간):** NPC 일정대로 움직인다. 범인의 행동도 일정표에 들어 있다(결정적 계산).
2. **발견:** 시신 칸을 처음 본 사람이 발견자다. 시선 판정으로 결정되고, 플레이어가 먼저 보면 플레이어가 발견자다.
   - 화면이 '발견' 사실과 지배인 방송을 만든다. 모든 NPC의 일정이 "현장으로"로 바뀐다.
3. **집합 장면:** 재판 대본과 같은 장면 엔진(대사 + 관계 변형)으로 고정 연출한다. **AI 호출 0회.**
   - 원하면 마지막에 플레이어 한마디 → AI 1회(현장 인물 반응).
4. **조사:** 시간 제한이 있다.
   - 지배인이 '검시 기록'을 증거 카드로 나눠 준다(화면 지급).
   - NPC는 조사 일정(현장 지키기, 자기 방, 증언 대기)으로 움직이고, 대화는 평소처럼 AI가 맡는다. 조사 중 증언은 기억 코드로 처리된다.
   - 로어북은 `#1장조사A` 표식 항목 하나만 켜진다: 진상 요약과 인물별 알리바이 주장, 각 3~4줄.
5. **개정:** 장마다 고른다.
   - (가) 정해진 시각에 방송으로 자동 개정
   - (나) 플레이어가 "조사 끝"을 선언하면 개정, 마감 시각은 있음
   - 1장은 (가)로 익히게 하고, 2·3장은 (나)를 제안한다.
6. **재판 → 처형(고정 연출, 마지막 말만 AI 1회) → 장 표지.**

**비용:**
- 발견부터 개정 전까지 AI 호출은 플레이어가 말을 걸 때만 생긴다.
- 로어북 부담은 장마다 조사 항목 1개 + 재판 항목 1~3개다.

## 7. 갈래 구조와 로어북 예산 (Q10 분석)

**갈래가 많아지지 않게 하는 원칙:**
- **같은 범인 원칙:** B·C 갈래는 가능하면 범인을 그대로 두고 수법·시각·피해 장소만 바꾼다. 그러면 다음 장에 미치는 차이가 0~1명으로 줄어든다.
- **차이 항목(델타):** 2장 로어북은 기본(A 기준) 항목에, `#1B`처럼 앞 장 갈래 표식이 있을 때만 켜지는 짧은 차이 항목을 덧붙인다(예: "1B이면: 레오는 새벽 선착장에서 죽었다. 도하의 처형 이유는 같다").
- **장 표지 표식:** `1A2A3A` 형태로 지나온 길을 표시한다. 화면이 지금까지의 갈래를 기억하고 표식으로 보낸다.

**항목 수 예산(추정):**

| 종류 | 개수 |
|---|---|
| 기억(사실 1개당 1항목) | 60~90 |
| 시간대 항목(3장 × 2일 × 4시간대) | ~24 |
| 갈래 차이 항목 | ~25 |
| 조사 항목(장 × 갈래) | ~8 |
| 재판 항목 | ~12 |
| 인물 세부 사정 | ~11 |
| 진엔딩 | ~20 |
| 기타 | ~10 |
| **합계** | **약 170~200개 (한도 300 안)** |

한 번에 켜지는 것은 대략 시간대 1 + 차이 0~1 + 기억 3~6 + 인물 1~3개라, 합계 30,000자 안에 들어간다.
