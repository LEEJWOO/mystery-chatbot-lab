# 본편 완성에 필요한 이미지 목록 (2026-11-24 초안)

호스팅: 본편은 Cloudflare R2(유혈 장면 포함 — GitHub에 올리지 않음). 코드 안에 이미지 데이터를 넣지 않는다.

## 공통 규격
- **스탠딩:** 투명 PNG, 세로 2:3(권장 1024×1536 이상), 무릎 위 또는 허리 위. **같은 인물의 모든 표정은 같은 캔버스·같은 자세·같은 위치**(얼굴만 다르게) — 그래야 자동으로 '몸 + 얼굴 조각'으로 나뉜다. 옷·자세가 바뀌면 별도 몸 세트.
- **배경:** 세로 2:3(600×900 이상, 권장 1200×1800), 인물 없이.
- **장면 CG:** 가로 16:9(1600×900 이상).
- **증거 아이콘:** 정사각 1:1(512×512), 배경 투명 또는 단색.
