## 재판에서 맞춰야 할 조각(현재 설계 기준)
- 다섯 증언: 각자 "저스틴이 내게 ○○를 말했다" + 파트너의 면담 시각 → 다섯 장소가 한 계획이었다 → 숨긴 사람은 저스틴(진열장에 4개였는데 숨긴 건 5개 → 하나는 저스틴 몫, 추정).
- 팔찌: 해제 감지 18:40이 사망 시각처럼 보임 → 시신의 상태·물때로 실제 사망은 그 뒤 → 지배인 "처형은 집행되지 않았다".
- 비탈: 자국은 바룬 것뿐(바룬 인정) → 비탈로 올라간 사람은 없다 → 저스틴은 다른 길(바다 쪽 바위벽, 썰물)로 갔다.
- 밧줄 사다리: 원래 있었다(누가 봤나?) → 사라짐 → 걷어 낸 사람 = 바룬 → 사다리가 있었다면 살 수 있었다 → 규칙상 범인 바룬.
- 바룬은 재판 내내 사고 경위를 모르는 상태에서 진실을 듣는다.
