# 트릭 노트 (트릭 먼저 → 인물·동기 끼워 넣기)

> 2026-11-26. 사용자 방침: 매력적인 트릭을 먼저 만들고 나머지를 끼워 넣는다. 아래는 후보·참고이며 확정 아님.

## 참고 1. 「RIGHT / LEFT」 (사용자 원안 2026-09-22, 본편 2장 예정)
- 지하 창고, 목 근처 자상·흉기 없음·염분 → "얼음칼" 가설(RIGHT)은 범인이 준비한 함정. 실제 사인은 드라이아이스에서 나온 이산화탄소 축적(LEFT). 상처·염분은 사후 위장.
- 반전 4: 상처≠사인 / 흉기 부재≠사라지는 흉기 / "쓰러질 때 아무도 없었다"는 사실일 수 있음 / 같은 곳의 무사한 사람≠환경 원인 배제.
- 범인 특정은 별도: 교대 순번·기록·증언 + 범인만 아는 현장 정보.
- 3단 재판(가설 완성 → 붕괴 → 사인·범인 분리 논증). 지킬 것: RIGHT/LEFT 대비, 전후반 의미 반전, 사인과 범인 분리.

## 참고 2. 《스테퍼 케이스》 Case 4 「겨우살이」 (요약만, 원문 아님)
- 불사의 피해자(해로운 것을 몸에서 끊는 능력)가 굶어 죽음. 신뢰 강제 능력자가 감시관을 조종해 식사에 진통제를 넣게 하고, 타임리프 능력자의 선의의 경고("식사 표면에 독")가 피해자의 능력을 음식 전체로 발동시킴.
- 최종 반전: 피해자와 그 방 자체가 물체 생성 능력자의 무의식이 만든 존재.
- 뼈대: 겉보기 사인≠진짜 사인 / 피해자 쪽 조건이 마지막 고리 / 실행자≠책임자 / 범인은 지식·능력 흔적으로 따로 특정.

## 후보 A. 「정지 잠수」 (능력 불필요)
- 피해자 프리다이빙 선수, 범인 라이프가드(버디). 피해자는 "9시 수영장 정지 잠수 기록 도전, 20분간 건드리지 마"를 선언.
- 20:30 만에서 깊이 연습. 범인이 깊이 표식을 5m 아래로 옮김 → 상승 중 기절 → 구하지 않음. 시신을 수영장에 엎드려 띄움(정지 잠수 자세 = 익사체와 같은 모습), 범인은 21:00부터 라운지 알리바이.
- 21:00~21:20 모두가 "훈련 중"인 시체를 구경. "21:05에 손가락이 까딱"(순환 물줄기 탓).
- RIGHT: 그 시간 누군가 눌렀다. LEFT: 다이빙 시계(20:31 시작·최대 24.8m, 풀 깊이 1.6m), 수압 손상, 물줄기 재현.
- 범인 특정: 25m 잠수엔 버디 필수, 표식의 구조용 매듭, 계획 변경을 범인만 앎. 예방: 버디 부탁 수락·20:30 만.

## 후보 B. 「옮겨진 상처」 (의사 능력)
- 능력: 상처 옮기기(양손 접촉, 같은 자리로, 박힌 이물 포함). 제약: 의식 있는 사람에겐 불가(자는·기절·죽은 조직만).
- 범인 셰프: 수면제로 잠든 피해자를 냉동 창고 고기 자루에 → 조리복 입은 채 자해 → 의사에게 "통돼지에 옮겨 줘" → 어둠·냉기로 의사가 고기로 믿고 옮김 → 둘이 함께 의무실(알리바이=범행 시간).
- RIGHT: 잠긴 창고·흉기 없음·자해 각도·수면제 → 자살. LEFT: 셔츠는 멀쩡한데 자상, 상처 속 조리복 섬유, 구멍 난 조리복과 상처 없는 셰프, 상처 없는 통돼지.
- 의사가 재판 중 자신이 흉기였음을 깨닫는 감정 정점. 예방: 의사 동행.

## 후보 C. 「두 번 울린 트로이메라이」 (능력 불필요, 클라라 누명)
- 자동 연주 피아노(녹음·재생 기록), 직원이 없어 내부 시계 20분 틀림. 클라라는 매일 22:00 불 꺼진 라운지에서 연주.
- 범인(뮤지션)은 첫날 녹음 → 당일 22:00 클라라는 실제 연주, 범인은 다른 곳에서 살해 → 22:20 작은 소리로 재생해 "22:00 재생" 기록을 만듦.
- RIGHT: 자동 재생이니 클라라 알리바이 없음 → 클라라 범인. LEFT: 22:00 연주의 실수가 녹음엔 없음, 시계 오차, "두 번 들렸다" 증언.
- '알리바이 트릭의 흔적'을 만든 트릭. RIGHT/LEFT와 모양이 비슷해 2장과 떨어진 장 권장. 예방: 22:00 라운지 방문.
