# 재판 개편안 v2 (2026-11-28)

## 구성 원칙
- 재판은 시제품(20단계)보다 훨씬 길다. 엇갈린 증언과 반론 횟수를 크게 늘린다.
- **모든 재판에 들어감:** 엇갈린 증언(한 재판에 여러 번), 동선 재현, 꿈 조각 잇기, 진상 결정, 투표, AI 증언(W)·반론(R).
- **장에 따라:** 팔찌 기록 대조, 알리바이 시간표 채우기.
- **뺌:** 실 엮기, 구절 짝짓기(위 두 가지로 대체).

## 새 반론 흐름
1. 반론을 제기한 인물이 엇갈린 증언 화면처럼 혼자 여러 문단을 말한다(문단은 대본 고정).
2. 플레이어가 맞는 문단에 맞는 증거를 쏘면 → 증거 제출 + 자유 입력 창(AI 판정, 로어북 조건·e 코드).
3. 틀린 문단·틀린 증거 → 엇갈린 증언 오답과 같은 처리(체력 감소, 상대 반응, 플레이어 독백).
4. 자유 입력이 조건을 못 맞추면 → 체력 감소 후 같은 자유 입력 창에서 다시. 상대는 상황에 맞는 새 대사, 플레이어도 독백. **대사 재탕 금지.**

## 꿈 조각 잇기 (문장형)
- 왼쪽에 전/후 전환 탭. 각 조각은 칸 목록 + 조사로 문장을 이룬다. 동작(가져갔다·숨겼다·건넸다…)도 고르는 칸.
- 칸 종류: 인물·시간·위치·물건·상대·동작. 조각마다 쓰는 칸과 순서를 정한다.
- 조사(이/가, 을/를, 와/과, 으로/로)는 고른 말의 받침에 맞춰 자동.
```
전: [인물]가 / [시간]에 / [위치]의 / [물건]을 / [동작]
후: [인물]가 / [물건]을 / [위치]에 / [상대]에게 / [동작]
```

## 팔찌 기록 대조
- 사진 시각·통화 기록·위치 조회 기록을 시간순으로 늘어놓고, 증언과 어긋나는 한 줄을 찍는다.
- 기록은 그 장에서 플레이어가 얻은 것만(남의 팔찌 기록은 수사로 얻은 경우만).

## 알리바이 시간표 채우기
- 증언을 보고 '누가 몇 시에 어디'를 칸에 채운다. 다 채우면 빈칸·겹침이 드러난다.
- 처음엔 검은 칸. 증언·증거로 칸이 열린다.
