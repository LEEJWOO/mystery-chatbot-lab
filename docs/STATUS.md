# 현재 상태 (2026-11-24) — 리뷰·인수인계용 요약

외부 리뷰어·다른 AI는 이 문서를 먼저 읽는다. 세부 정본은 [STORY.md](../STORY.md), 설계는 [docs/design/STAGE_TIME_UI.md](design/STAGE_TIME_UI.md), 코드는 [prototype/npc_topdown/](../prototype/npc_topdown/).

## 1. 확정 규모
| 항목 | 확정 |
|---|---|
| 참가자 | **12명**(플레이어 포함, 나머지 11명) + 바쿠(집사 역, 꿈의 주인) |
| 장 | **3장**, 장마다 1~2일 |
| 사망 | 장마다 **2명**(피해자 1 + 처형 1) → 노멀 루트 **6명 사망·6명 생존** |
| 무대 | 바다 위 폐업 리조트 호텔. 처음부터 열림, 이유 있는 곳만 잠김. 객실 출입 가능. 직원 없음 |
| 루트 | 노멀(꿈 속 시뮬레이션) + 진엔딩(새 채팅방, 현실, 가짜 살인·처형으로 0명 사망) |
| 플랫폼 | UUMMAI. 본문 프롬프트 + JSX 1개 + 로어북. 그림은 외부 호스팅(본편: Cloudflare R2) |

**15명·5~6사건 규모는 폐기된 옛 초안이다.** (docs/drafts/CAST_DRAFT.md의 규모 표 포함)

## 2. 구현 상태 (시험판 v1.1)
시험용 인물 4명(유리·도윤·세린·태수, 본편 아님)·시험 맵 1개(4개 방)·재판 시제품 1개로 시스템만 검증하는 단계다.

- 엔진: 결정적 NPC 일정·경로·만남, 기억(직접/목격/증언), 시선 차단, 사건 코드 검증, 시간대 갈래 표식, 이벤트 점프 시간 계산
- 상태 인계: 압축 상태 코드(세계 지문·데이터 버전 검사), TRM1 인계 메시지, 증언은 실제로 들은 줄까지만, 원본 줄 기준 끼어들기
- 화면: 2:3 세로, 방 단위 화면 전환, 도트 맵·4방향 걷기 스프라이트, 대화 화면(배경 + 인물 레이어 + 표정 조각), 휴식(시간 건너뛰기), 조사·증거, 인물 수첩, 목격 장면, 먼저 말 걸기
- 재판 시제품(13단계): 증언에 증거 제시, 엇갈린 두 증언, 구절 짝짓기, AI 반론(사건 코드 판정), 기억 현상, 동선 재현, 실 엮기, 꿈 조각 잇기, 진상 결정, 투표 / 재판 전용 체력·되감기
- 자동 테스트 35개, 브라우저 자동 확인. **UUMMAI 실기 확인은 v0.4까지만** — v1.0 실기 플레이는 다음 단계.

외부 견적에서 'A. 엔진 안정화 150~340시간'으로 잡힌 항목 대부분(증언 시점, 끼어들기, 지문, 시선, 상태 인계)과 '재판 미니게임 80~220시간'의 시제품이 위 시간 안에 끝났다. **AI가 코딩·테스트를 맡는 부분은 사람 단독 견적보다 10~30배 빠르다.** 대신 병목은 ① 창작 판단(사건·인물), ② 그림 제작, ③ 실기 플레이 테스트(시간·비용)로 옮겨 간다.
