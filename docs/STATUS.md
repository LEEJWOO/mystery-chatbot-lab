## 2. 절대 규칙 (어기면 사용자가 크게 곤란해짐)
1. **진행자의 정체(바쿠)·되감기 능력을 화면·대본·대사에 절대 쓰지 않는다.** 화면 표기는 항상 「지배인」.
2. **이미지(맵 포함)를 암호화·data URI로 JSX 안에 넣지 않는다.** 그림은 공개 GitHub 그림 브랜치에서 주소로 불러온다. 오프라인 HTML(data URI 포함)은 로컬 확인용이며 JSX에 섞지 않는다.
3. **맨몸·속옷·성인·고어 그림은 공개 저장소에 올리지 않는다.** 비공개 저장소(LEEJWOO/troemerei-private) 또는 압축 파일로만.
4. **RPG Maker 타일셋 원본은 공개 저장소에 올리지 않는다**(비공개 저장소 tilesets/에만). 구운 맵 그림만 공개 그림 브랜치에.
5. **인물 표시 규칙** ([DISPLAY_RULES.md](../prototype/npc_topdown/docs/DISPLAY_RULES.md)): 같은 인물 그림 사이에 배율·위치 보정 금지(인물마다 배율 1개·y 1개). 실제 키로 위치 계산 금지. 문제는 그림을 고치고 표시를 고치지 않는다. 벗어나려면 먼저 사용자와 상의.
6. **main 병합은 사용자가 "메인에 병합해 줘"라고 할 때만.** 작업 브랜치는 `troemerei/v2.0`.
7. 체험판 데이터(`src/world.json`)는 고치지 않는다. 본편은 `src/world_ch1.json`(빌드 산출물).
8. Cloudflare 비밀번호는 받지 않는다. 버킷 한정 토큰만, 쓰고 나면 폐기.
9. 잠긴 메모·장면에 힌트를 주지 않는다. UUMMAI에 그림을 직접 등록하지 않는다.
10. 그림 제작·가공(색 보정 등)은 사용자 몫. Claude는 정해진 굽기·추출 도구만 쓰고, 나머지는 요청서를 쓴다.
11. 있는 미니게임·데이터를 다시 쓴다. 처음부터 새로 만들지 않는다.

## 5. 1장 사건 (확정 요약 — 상세는 CH1_DECISIONS·TIMELINE·TRIAL_CH1_K1)
- **팔찌 장치**: 전원 동일. 전지 1개 12시간, 1인 8개, 남은 예비 4개는 로비 진열장. 기능(사진·통화·위치 조회 3시간)은 전지를 깎음. 일찍 뺀 전지의 남은 시간은 버려짐. 해제 감지 후 10분 안에 다시 안 차면 처형 — 단 **저스틴에게는 집행되지 않았다**(그 전에 익사).
- **저스틴의 미끼**: 진열장 4개 + 자기 몫 1개 = 5곳에 숨기고, 다섯 사람에게 각기 다른 자리를 "우리끼리만"이라고 알림(08:30 클라라·08:55 킬리언·09:15 프레디·09:40 스즈네·10:05 서하).
- **바룬**: 스즈네에게 전망 바위 이야기를 전해 듣고(09:55), 12:50 전망 바위 바다 쪽 밧줄 사다리를 걷은 뒤 13:10~19:00 벤치에서 비탈 입구를 지킴.
- **저스틴**: 오후 썰물에 갯바위로 가서 사다리 없는 바위벽을 맨손으로 오름(16:00 정상), 16:05 프레디가 위치 조회(전망 바위 위), 16:14 무렵 바위틈으로 추락·갇힘, 18:00 전지 교체, 18:40 팔찌를 바위 해안 쪽으로 던짐, 밀물에 익사.
- 20:20 수색대가 전망 바위 끝에서 발견 → 22:55까지 조사 → 재판 K1 → 범인(그 죽음을 일으킨 행동을 한 사람) = **바룬**.
- 벤치에서는 갯바위와 물가 바위턱이 **보이지 않는다**(능선, 테스트로 고정).

## 8. 열린 결정
- **벤치 시야**: 동업자는 "먼 갯바위는 보이고 진입 칸만 가리자"고 했으나, 벤치에서 보이는 갯바위는 전부 저스틴의 오후 동선 위라 보이면 바룬이 저스틴을 봤어야 함. 현재는 전부 가림. (추천: 그대로, 스즈네 그림의 물때는 해변 쪽 물가로 읽음)
- 저스틴 별명(초안, CAST_v2 저스틴 항목): 분홍이·소라빵·가운 누나·코트 누나·보라돌이·모자 장수·츄리닝 형·은갈치·퍼렁이·주방장·집사 양반·신입.
- 결말 대사, 처형 연출 수위, 진엔딩에서 두 사람을 살리는 개입 조건.
