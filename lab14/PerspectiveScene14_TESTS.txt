PerspectiveScene14 · 14차 2.5D 탐색 테스트 기록 (2026-10-27)
등록명: PerspectiveScene14
호출: <PerspectiveScene14 />
저장 스키마: v=2, protocol=PERSPECTIVE_V1. 13차 v1을 덮어쓰지 않음.

설계 시험값 (사용자 확정 수치가 아님)
- 11x9 월드. 서쪽 큰 공간/동쪽 작은 자료실/한 칸짜리 문.
- 캐릭터 시작: (3,4) 타일 중심, 동향, 09:05:00.
- heading: 0 북, 1 북동, 2 동, 3 남동, 4 남, 5 남서, 6 서, 7 북서.
- 수평 시야각 120도, 가시 범위 9 타일, 타일 1.5m, 이동속도 0.95m/s.
- 기본 이동 2초, 대각선 3초. 제자리 45/90도 회전 0초.
- 왼쪽 조명 켜짐, 오른쪽 자료실 조명 꺼짐. 문은 닫힘.

UUMMAI 실제 순서
1. 등록 화면에 PerspectiveScene14_UUMMAI.txt 본문 전체를 복사하고, 등록 이름을 PerspectiveScene14 로 지정한다.
2. 챗봇 규칙에 PerspectiveScene14_MAIN_PROMPT.txt를 추가한다. /14차 입력 후 <PerspectiveScene14 /> 화면이 보이는지 확인한다.
3. 처음 위치는 (3,4), 방향 동, 시간 09:05:00인지 확인한다. 기본 화면에 문, 스위치, 책상의 일부가 보인다.
4. ↶45°를 8회 또는 ↷90°를 4회 눌러 원방향 복귀. 좌표/시각/가방은 불변이어야 한다.
5. 탐색 화면의 문 또는 스위치를 눌러 관찰한다. 0초 증가 및 자동 수집 없음.
6. 오른쪽 이동 2번하여 (5,4)로 간다. 시간 09:05:04. 문을 눌러 관찰하고 '문 열기 +4초'를 실행한다. 시간 09:05:08.
7. 스위치를 누르고 '자료실 조명 켜기 +1초' 실행: 09:05:09. 멀리 자료실 내부가 밝아지고 기록부가 보여야 한다.
8. 동쪽으로 2번 이동하면 (7,4), 시간 09:05:13. 기록부를 누르면 0초 관찰되며 아직 가방에 자동 추가되지 않는다. 자세히 조사는 40초이며 거리가 멀면 먼저 접근해야 한다.
9. 다시 서쪽 문으로 돌아와 닫힘 상태의 모서리로 대각선 이동 시도 테스트. 막힌 이동은 시간/위치 불변.
10. 기록 탭에서 실제 MOVE 시작/도착/초 단위 actionLog를 확인한다.
11. 저장·인계 탭의 현재 체크포인트를 복사, 다른 위치로 이동한 뒤 복원 JSON 입력란에 넣고 '복원' 실행. 같은 위치/시야/시간/발견 지도/증거 기록 복귀.
12. 임의의 말 입력 후 AI 인계 버튼 클릭. state와 사용자 발화가 1회 전송되어야 하며 성공 후 기존 패널은 잠김. UUMMAI에서는 직접 확인 필요.

환경별 증거
- Node 순수 엔진/투영/검증: 13/13 통과.
- 실제 SVG 시야 결과: initial/open 두 가지를 SVG+PNG로 렌더하여 시각 확인. 문이 열리면 가운데 구멍이 생기고 내부 물체가 보이는 것을 확인.
- UUMMAI JSX UI 등록/실제 클릭: 미검증. 사용자가 플랫폼에 등록해 확인해야 함.
- React 브라우저 전체 JSX 호스트 실행 및 모바일 터치: 미검증. 정적 SVG 확인을 브라우저 UI 실증으로 간주하지 않음.
- Worker/Cloudflare: 미배포, 14차에서 필수 아님.
- AI 인계 sendMessage: 로컬 payload 함수만 테스트. 호스트 수신 및 회복 미검증.

알려진 범위/제약
- 본 차수는 2.5D 레이캐스트+기하 도형 기반 저충실도 PoC. 물체의 부분 가림은 벽 깊이 기반 열별 클리핑이며 복잡한 메시/가구 간 자체 차폐는 미구현.
- 물체는 월드 좌표 기반 원근 투영이며, 화면의 배경 그림만 바꾸는 모형이 아님.
- 완성된 캐릭터 대사/VN/능력치/사건 인과/AI 모델 보안 인증/서버 장기 저장은 향후 통합 과제.
- 현재 13차 v1 자동 이관은 없음. 13차 좌표/사건 규칙이 새 시험 맵과 달라 임의 이관하면 잘못된 데이터가 되므로 명시적으로 분리.
- XML SVG 정적 미리보기 이미지의 한국어 글자가 환경 폰트에 따라 네모로 보일 수 있으나, 우마이 JSX 텍스트 렌더링은 별도 확인 대상.
- 이 테스트 코드는 LLM 버튼당 호출하지 않는다. 전송은 사용자의 명시적 인계 한 번이다.
